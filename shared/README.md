# Shared Grant Resources

Reusable boilerplate, templates, and institutional language that can be drawn upon in any proposal.

## Contents

| Folder / File | Purpose |
|:---|:---|
| `boilerplate/` | Standard narrative blocks: CHI mission statement, facility descriptions, diversity statements |
| `budget-templates/` | Budget spreadsheet templates and indirect cost rate notes |
| `biosketches/` | Current PI and co-PI biographical sketches (update each academic year) |
| `institutional/` | Institutional letters of support templates, DUNS/SAM registration notes |

## Usage

Copy relevant files into the active proposal folder (`proposals/YYYY-sponsor-short-title/`) rather than editing originals here. This keeps shared files reusable across submissions.

## Updating Shared Resources

- Update `biosketches/` at the start of each academic year
- Update `boilerplate/chi-mission.md` whenever CHI's mission statement is revised
- Note the last-reviewed date at the top of each shared file
